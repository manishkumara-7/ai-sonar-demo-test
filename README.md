# AI + SonarQube Security Automation Demo

This repository demonstrates an end-to-end secure SDLC workflow using:

- Java (Maven)
- SonarQube (Local)
- Cursor AI
- GitHub Pull Requests

## Workflow
1. Code is committed to GitHub
2. SonarQube scans the repository
3. Vulnerabilities are identified
4. Cursor AI suggests fixes
5. Fixes are submitted via Pull Requests
6. SonarQube validates resolution

## Goal
Demonstrate AI-assisted vulnerability remediation with human review.
